# TODO-List

A simple and intuitive To-Do list application that allows users to manage their tasks through different stages: To-Do, In Progress, and Done.

## Features and Functionality

*   **Add Tasks:**  Users can add new tasks to the "To-Do" list by entering them in the input field and clicking the "Add Task" button.
*   **Move Tasks:**  Tasks can be moved between the "To-Do", "In Progress", and "Done" lists using the arrow buttons associated with each task.
*   **Delete Tasks:** Users can delete tasks from the "To-Do" and "Done" lists using the "Delete" button.
*   **Clear Input:**  The input field clears after adding a task.
*   **Visual Task Management:**  Provides a clear visual representation of task progress across different stages.

## Technology Stack

*   **HTML:**  Used for structuring the web page and defining the layout.  Key elements are located in `index.html`.
*   **CSS:**  Used for styling the web page and providing a user-friendly interface. (The contents of `style.css` were not provided, so the README assumes its existence).
*   **JavaScript:**  Used for handling user interactions, manipulating the DOM, and managing the task lists.  Key logic is located in `script.js`.

## Usage Guide

1.  **Adding a Task:**
    *   Enter the task description in the input field labeled "Enter your task...".
    *   Click the "Add Task" button. The task will be added to the "To-Do" list.

2.  **Moving a Task:**
    *   To move a task from "To-Do" to "In Progress", click the right arrow (`&RightArrow;`) button on the task in the "To-Do" list.
    *   To move a task from "In Progress" to "Done", click the right arrow (`&RightArrow;`) button on the task in the "In Progress" list.
    *   To move a task from "In Progress" back to "To-Do", click the left arrow (`&larr;`) button on the task in the "In Progress" list.
     *   To move a task from "Done" back to "In Progress", click the left arrow (`&larr;`) button on the task in the "Done" list.

3.  **Deleting a Task:**
    *   To delete a task from the "To-Do" list, click the "Delete" button on the task.
    *   To delete a task from the "Done" list, click the "Delete" button on the task.
